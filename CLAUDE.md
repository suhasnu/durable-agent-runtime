# durable-agent-runtime

A learning project. I am building this to understand agent runtimes, not to
ship it fast.

## How to help me

Do NOT write implementation code in agentrt/. I write those files myself.
If I ask for an implementation, give me the reasoning, the tests, and the
APIs to use, then let me write it.

You may freely: run tests, explain failures, review code I have written,
handle git, write CI config and docs.

## Conventions

- Prose uses commas, not dashes, between words.
- Comments only on non obvious decisions.
- Tests run against a scripted provider, never the network.
